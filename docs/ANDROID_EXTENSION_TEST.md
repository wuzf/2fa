### Edge 手机布局调整与回归

原生 Edge popup 的可用空间大于原来的固定 380 × 600 CSS px，界面只占容器左上角。本次修改共享 `popup.css`：粗指针视图铺满可用宽高，主要触控区域增至 44–48 CSS px，记住账户与自动填充偏好分两行；视口高度不超过 480 CSS px 时，`main` 整体滚动，使账户和底部偏好可分别到达。

已安装版本的 `popup.css` SHA-256 为 `65766cccee3b103538cba5c8381305d19d5aeb6067a1ac4b46fd2f910fe27b51`。实测原生 popup 的 554 × 768 CSS px（density 240）、344 × 461 CSS px（density 400）、554 × 259 CSS px 横屏均无横向溢出。后两种尺寸可通过滚动看见两个偏好控件；手机尺寸还再次完成手动填充。

尝试将 `show_ime_with_hard_keyboard` 设为 1 后仍未出现软键盘，随后恢复为 0。因此本轮仍未实测软键盘弹出时的布局；短视口测试不能替代这项验证。测试也未使用真实手机或真正断网，未验证商店签名安装与更新。

对应源码回归已通过：`popup-layout.test.js` 的 3 项测试，以及 Chrome / Edge 各 1 项限定布局 E2E。布局 E2E 覆盖中、英、德三种语言和 320 × 480、360 × 360、412 × 720、554 × 768、1067 × 400 CSS px，检查移动视图铺满、短视口滚动可达和末张账户显示；切回普通指针后检查桌面尺寸仍为 380 × 600。此自动化使用桌面 Chromium，不替代原生 Android 交互测试或桌面 Firefox 渲染验证。

最终已运行 `npm run package:extension`，重新生成包括 Edge 和 Firefox 在内的 1.1.2 扩展安装包；打包完成不表示已发布至浏览器商店。
