# v1.13.1：统一弹窗关闭与未保存内容保护

修复 [#23](https://github.com/wuzf/2fa/issues/23) 反馈的功能弹窗关闭方式不一致问题。

## 弹窗交互

- 点击弹窗外部、按 Esc、点击关闭或取消使用相同的关闭规则。没有未保存内容时直接关闭；表单输入、待导入文件等尚未保存时，先询问是否放弃，选择「继续编辑」会保留原有内容。
- 统一手动添加、批量导入、批量导出、备份与还原、系统设置及下级工具弹窗的关闭行为。离开批量导入、转去扫描迁移二维码时，也会保护尚未导入的内容。
- 嵌套弹窗只关闭最上层。在放弃修改的确认框中按 Esc 或点击背景，表示取消关闭，不会连带关闭底层表单。
- 关闭设置时等待最新修改的自动保存，等待期间再次编辑也会纳入检查；保存成功后直接关闭，保存失败或密码表单尚未提交时询问是否放弃。
- 设置保存超过 5 秒仍未完成时，允许继续编辑或确认关闭，并明确提示关闭不会撤销已提交的保存，避免网络请求挂起时无法退出。
- 迁移预览出现关闭确认后，在另一标签页切换语言会原位更新文案，保留已选账户和确认框层级，不再遮挡确认框或使关闭操作失效。
- 从弹窗内部拖动到外部松手不会误触关闭。关闭仍执行原有的摄像头、计时器和导入状态清理。
- 新增确认文案覆盖项目支持的 15 种语言。

## 升级说明

从 `1.13.0` 升级无需数据迁移，后端 API 和账户存储格式保持一致。按[升级指南](https://github.com/wuzf/2fa/blob/v1.13.1/docs/DEPLOYMENT.md#升级指南)更新后刷新页面，确认页脚显示 `1.13.1`。

浏览器扩展继续使用 `1.3.0`。
