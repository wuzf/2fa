# v1.9.0：统一界面与连续验证码预览

## 改进内容

- 统一主页面、设置与工具弹窗、初始化页面和 HTML 备份的 Fluent 2 风格，优化主题切换与响应式布局，并支持用方向键在账户卡片和菜单间移动。
- 公开 OTP 网页同时显示当前和下一期 TOTP，均可点击复制，到期后原地更新。HOTP 网页仍显示链接中指定计数器的验证码，复制不会推进计数器。
- 账户卡片菜单区分“复制 URI”和“复制网页链接”，保留算法、位数、周期及 HOTP 计数器等参数。两种链接都包含账户密钥，请按密钥本身妥善保管。
- 登录有效期和备份保留数量修改后自动保存；修复取消 WebDAV、S3 配置后控件无法恢复的问题。登录有效期调整在下次登录时生效。
- 改进验证码迁移和备份兼容性，保留 HOTP 计数器及算法参数，修复二维码中的中文与 emoji、CSV 转义字符及 HTML 备份账户名称的解析问题。

公开 OTP 接口的默认 JSON 响应仍为 `{ "token": "…" }`。TOTP 请求显式添加 `preview=1` 时，可获得后续验证码及有效时间；HOTP 保持单验证码响应。

## 升级方法

1. 升级前导出数据备份，并确认已妥善保存原 `ENCRYPTION_KEY`。
2. 在自己的仓库中打开 **Actions → Sync Upstream → Run workflow**，将上游分支或标签填写为 `v1.9.0`。
3. 等待同步及 Cloudflare 部署完成，刷新页面并确认版本为 `1.9.0`。

继续使用现有 Worker、KV 绑定和密钥，无需删除或重建实例。使用附件手动升级时，只替换原 Worker 的代码；完整步骤见[部署指南](https://github.com/wuzf/2fa/blob/v1.9.0/docs/DEPLOYMENT.md)。
