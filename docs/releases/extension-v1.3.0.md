# 浏览器扩展 1.3.0

Chrome、Edge、Firefox 扩展统一升级至 `1.3.0`，扩展与 2FA 主程序独立编号。本次改进身份验证器页面的输入框识别，修复圆角弹窗中的可见输入框被忽略的问题。

## 通用 Code 输入框

单个输入框只写着“Code”或“Enter code”时，以前即使页面说明验证码来自身份验证器，也需要先点击输入框再填充。现在同时满足以下条件时，可识别为身份验证器验证码框：

- 附近标题或说明明确要求使用身份验证器验证码，例如“Get your code from your authentication app”；只把身份验证器列为另一种验证方式不算。
- 输入框通过 `maxlength` 或 `pattern` 限定 6 位或 8 位。
- 附近没有短信或邮件投递说明、发送或重发按钮、发送倒计时等迹象，包括“Text me a code”这类指定渠道的发送按钮。
- 输入框没有恢复码、备用码等其他用途的标识。

满足识别条件后可直接手动填充；自动填充仍需网站授权及明确的账户匹配。条件不足或有多个候选输入框时，仍可能需要先点击目标输入框；恢复码、备用码字段不会因此变成自动填充目标。

## 圆角弹窗

修复 `clip-path: inset(0px round 32px)` 一类圆角裁剪导致整块弹窗被视为不可见的问题，例如 Meta 账户中心的弹窗。可见输入框现在可参与自动填充、弹窗手动填充和聚焦填充的识别。

完全裁掉的输入框仍会被排除；这项修复只处理带圆角的 `inset()`，不代表支持任意 `clip-path` 形状。

## 安装包

- Chrome：`2fa-extension-chrome-1.3.0.zip`
- Edge：`2fa-extension-edge-1.3.0.zip`
- Firefox：`2fa-extension-firefox-1.3.0.zip`

本地加载的扩展更新后需要重新加载。Firefox 正式版临时加载未签名安装包后，重启浏览器需重新载入；Android 普通安装需要兼容 Android 的签名版本。商店版本以各商店实际提供的版本为准，安装步骤和平台限制见[浏览器扩展指南](../BROWSER_EXTENSION.md)。
