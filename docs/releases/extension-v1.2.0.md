# 浏览器扩展 1.2.0

Chrome、Edge、Firefox 扩展统一升级至 `1.2.0`，扩展与 2FA 主程序独立编号。本次新增 Android 支持与 HTTP 页面自动填充，并减少开启自动填充所需的操作：填充时即可一并开启，授权范围从单个页面扩大到整个网站。按功能版本升级；开发测试阶段使用的 `1.1.2` 不作为本次最终版本。

## Android 浏览器

- 新增 Firefox Android 支持，最低版本为 153；适配缺少快捷键 API、普通标签页信息差异及全屏扩展页面中的手动填充。
- 保留普通标签页和权限边界；不支持隐私标签页，Firefox 桌面版仍仅支持默认容器。
- Edge Android 和 Firefox Android 的触控界面适应浏览器分配的宽高，增大操作按钮，账户记忆与自动填充选项分行显示；横屏等较短视口可滚动访问全部内容。
- 调整英文弹窗头部：保留完整产品名称，页面提示与导航链接共用下一行，减少顶部空白。
- 已在 MuMu 中验证 Firefox 156 和 Edge Canary 144 的连接、复制、填充、授权与离线缓存。浏览器版本、测试包版本和限制见 [Android 验证记录](../ANDROID_EXTENSION_TEST.md)；模拟器结果不代表商店签名安装或所有手机环境均已验证。

## 填充时开启自动填充

- 原来的“记住账户”和“在此页面自动填充”合并为填充按钮下方的“以后在此网站自动填入 某账户”。网站还没有记住的账户，或所选账户就是记住的账户时，默认勾选。
- 勾选后点击“填充”：验证码照常填入，同时记住该账户；此网站尚未开启自动填充时，同一次点击会请求浏览器授予此网站的访问权限，允许后开启此网站的自动填充，拒绝则只填入并记住账户，弹窗会说明结果。
- 浏览器在权限提示期间关闭弹窗时，授权完成后扩展仍会保存该账户和网站授权，并在页面上自动填入。
- 自动填充仍不会默认开启：取消勾选后填充，不申请权限，也不开启自动填充。2FA 实例本身等无法授权的页面，复选框仍写作“记住 某账户”。

## 按网站授权

- 自动填充按网站授权，开启后覆盖同一网站的所有页面路径，登录流程中途跳转到其他路径的验证页也能自动填入。协议、主机或端口不同仍是不同的网站。
- 弹窗底部改为“在此网站自动填充”，关闭时停用该网站的全部自动填充授权。
- 设置页“网站设置”中，整个网站的授权显示为“整个网站”及开启时所在的页面，可以改为“仅限此页面”或停用。
- 1.1.1 及更早版本的页面授权升级后保持原样，不会自动扩大；这些页面在弹窗中仍显示“在此页面自动填充”。在同一网站的其他页面开启自动填充时，会改为授权整个网站。

## HTTP 页面自动填充

- HTTP 页面（包括内网 IP 和域名）现在也可以开启自动填充，移除原来的“只能手动填充”限制和提示。
- 自动填充仍需用户明确开启并授予网站访问权限，授权范围按协议、主机和端口区分。
- 已保存且仍有浏览器访问权限的 HTTP 页面授权会继续保留；已被旧版本移除的授权需要重新开启。

## 常见服务的账户匹配

- 新增常见服务官方登录页与账户名称的对应，名称唯一匹配时无需先记住账户即可自动填入：V2EX、Dropbox、Reddit、Twitch、Epic Games、PayPal、Coinbase、Binance、Kraken、Amazon、AWS、Yahoo、Proton、Mozilla（Firefox 账户）、Bitwarden、Atlassian、Stripe、DigitalOcean、Heroku、Docker、Vercel、Hugging Face、OpenAI、Namecheap、Hetzner。
- 只认官方登录主机，不扩展到子域名或租户域名；同一服务有多个可能匹配的账户时，仍需手动选择或记住账户。

## 填充识别与稳定性

- 改进验证器输入框、延迟出现的表单及分格验证码识别，区分短信、邮件验证码和其他验证方式，减少误填。
- 加强页面切换、来源标签页和扩展页面生命周期检查，避免向已经失效的目标页面填入验证码。
