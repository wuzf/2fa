# v1.10.0：Chrome / Edge / Firefox 验证助手

## 浏览器扩展

新增配套的 Chrome / Edge / Firefox“2FA 验证助手”，连接自托管 2FA 实例后，可查看和复制 TOTP、手动或通过快捷键填充，并在用户逐页面授权后自动检测验证码框。

- [从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/2fa-%E9%AA%8C%E8%AF%81%E5%8A%A9%E6%89%8B/lifeiloiefdlbohelpjajdbopeocalhl)。
- [从 Microsoft Edge Add-ons 安装](https://microsoftedge.microsoft.com/addons/detail/kmchncmoddhdlbpfoejeahdjhieghklm)。
- [从 Firefox 附加组件商店安装](https://addons.mozilla.org/zh-CN/firefox/addon/2fa-%E9%AA%8C%E8%AF%81%E5%8A%A9%E6%89%8B/)。
- 也可以下载本页附件中的安装包手动安装，见下方“发布附件”。

主程序与扩展独立编号。本次主程序版本为 `1.10.0`，Chrome、Edge、Firefox 扩展版本均为 `1.1.1`。扩展需连接自托管 2FA 实例，支持账户搜索、常用账户、验证码预览、手动填充和按页面授权的自动填充。Firefox 需使用 153 及以上桌面版本的普通标签页，不支持容器标签页、隐私窗口或 Android。

扩展 `1.1.1` 改进了验证码框识别：页面有重发按钮、写明验证码已通过短信或邮件发送，或输入框旁有“获取验证码”一类发送按钮时，需先点击输入框再填充，避免把 TOTP 验证码填进短信或邮件验证码框。同一页面路径在一次页面加载内只自动填充一次；私网地址的 HTTP 页面只能手动填充；离线使用时，扩展后台重启后会沿用 15 分钟内的校时结果。

网页登录模式无需保持实例标签页打开；用户可主动启用离线缓存。离线缓存包含原始密钥，没有额外密码加密，只应在可信设备上启用。安装、权限和使用范围见[扩展指南](https://github.com/wuzf/2fa/blob/v1.10.0/docs/BROWSER_EXTENSION.md)、[Chrome / Edge 隐私说明](https://github.com/wuzf/2fa/blob/v1.10.0/extension/PRIVACY.md)及[Firefox 隐私说明](https://github.com/wuzf/2fa/blob/v1.10.0/extension/PRIVACY_FIREFOX.md)。

## 15 种语言

网页、浏览器扩展、首次设置、公开 OTP 页面、接口提示及备份文档统一支持 15 种语言：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português (Brasil)、Italiano、Русский、Türkçe、Bahasa Indonesia、Tiếng Việt、ไทย。

- 界面可跟随浏览器或手动选择，未支持的浏览器语言回退英文；首次设置时即可选择语言，切换后在已打开的标签页间同步。
- 不同语言导出的 CSV / HTML 备份可相互导入。保存到 KV 和远程存储的 CSV 备份始终使用简体中文表头，回滚旧版本后仍可恢复。
- 扩展的显示语言在扩展设置中单独选择；浏览器扩展管理页中的名称和描述随浏览器语言显示。

## 网页与部署改进

- 优先展示本地缓存账户，改进恢复联网、会话变化与 PWA 更新处理。
- 改进账户编辑保存与离线队列恢复，减少异步响应覆盖当前编辑状态的问题。
- 保留部署时显式指定的账户库绑定，隔离不同环境，降低升级错误连接存储的风险。
- 离线保存前按服务器规则校验；被服务器拒绝的离线修改会停止重试、显示原因，并可“编辑后重试”。离线添加的账户如果服务器上已有完全相同的一条，或离线删除的账户已被删除，视为已完成，不再报错。
- 恢复备份时逐条校验。OTP 参数不受支持的条目原样保留在服务器上，恢复前会提示；有条目无法解析时，拒绝恢复不完整的备份。
- 编辑账户改为部分更新，未修改的周期、位数和计数器保持原值；更换 HOTP 密钥、位数或算法时，未填写的计数器从 0 开始。

## 升级方法

1. 升级前导出数据备份，并确认已妥善保存原 `ENCRYPTION_KEY`。
2. 在自己的仓库中打开 **Actions → Sync Upstream → Run workflow**，选择上游 `main` 或本次发布标签 `v1.10.0`。
3. 等待同步和部署完成，刷新网页并确认显示 `1.10.0`。

升级继续使用现有 Worker、KV 和密钥，不需要删除或重建实例。扩展从相应浏览器商店安装，在同一浏览器中登录自己的 2FA 实例后连接。

## 发布附件

`worker.js`、`worker.metadata.json` 和 `DEPLOY.md` 用于单文件 Worker 部署和版本核对。另附扩展 `1.1.1` 的安装包，可下载后自行安装。所有附件均从 `v1.10.0` 标签源码构建。

- `2fa-extension-chrome-1.1.1.zip`、`2fa-extension-edge-1.1.1.zip`：解压后，在 `chrome://extensions` 或 `edge://extensions` 打开“开发者模式”，点击“加载已解压的扩展程序”（Edge 为“加载解压缩的扩展”），选择解压出的文件夹，也就是直接包含 `manifest.json` 的那一层。之后不要删除或移动这个文件夹。
- `2fa-extension-firefox-1.1.1.zip`：未经 Mozilla 签名，正式版 Firefox 只能临时载入。打开 `about:debugging#/runtime/this-firefox`，点击“临时载入附加组件”，直接选择这个 zip 文件；浏览器重启后需重新载入。长期使用请从 Firefox 附加组件商店安装。

手动安装的扩展不会自动更新，从商店安装可自动获得更新。Chrome / Edge 手动加载的扩展与商店版分别保存设置；Firefox 安装包与商店版是同一个附加组件，临时载入后，在浏览器重启前会代替商店版。
