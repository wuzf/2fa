# v2.0.0：主题与自定义代码

本版本新增主题系统和自定义代码：可以换用社区主题、导入自己做的主题，也可以从模板开始制作完整的前端界面，或在设置中加入自己的 HTML、style 和 script 代码。账户、验证码、HOTP、离线队列和备份继续使用原有的同一套逻辑；升级不需要迁移数据，账户存储格式和账户相关 API 没有变化。浏览器扩展继续使用 `1.3.0`。

## 外观与主题

- 打开 **设置 → 外观与主题**，可以选择官方默认主题、已安装主题或社区主题。右侧用示例账户预览，可切换桌面、平板、手机和浅色、深色；点击 **应用外观** 后保存到实例，当前页面随即换上新外观，其他设备在下次打开页面时切换。
- 主题有两种格式：**v1** 只调整官方页面的布局、卡片、配色和字体，不执行主题 JavaScript；**v2** 是完整前端主题，通过 SDK API 1 使用 2FA 的账户和功能，可以重新设计整个界面。
- **v2 主题不是沙箱**：主题脚本与 2FA 页面同源运行，可以读取账户数据、发送网络请求。应用 v2 主题前会再次确认，请只使用自己信任的作者和版本。
- **社区主题** 列出官方目录 [wuzf/2fa-theme-mytheme](https://github.com/wuzf/2fa-theme-mytheme) 和自己添加的主题目录（公开 GitHub 仓库，最多 5 个）中尚未安装的主题。**导入主题** 可以安装本机的主题 ZIP（最大 12 MB）。每个实例最多安装 20 个主题。
- 同一主题只保留一个已安装版本，安装新版会替换旧版；新版校验或保存失败时保留原来的版本。主题设置按字段保留，失效的设置会提示调整。
- **自动更新官方主题** 默认开启：每天北京时间 0 点检查官方目录，从官方目录安装的主题有新版时自动更新。导入的 ZIP、自己目录中的主题，以及要求更高 2FA 版本、申请新权限或设置不再兼容的新版，仍在社区主题中提示手动更新。
- 主题卡片显示主题截图，并标出当前使用的主题。
- 换到另一个主题时，先下载并校验新主题的全部文件，准备好后再刷新页面切换；下载失败时继续使用原来的主题。
- 主题导致页面无法使用时，访问 `https://你的域名/?safeMode=1` 临时停用主题和自定义代码，在基础界面中修正后，用页面上的按钮退出安全模式。
- 主题、主题设置和素材保存在 Durable Object `SECRETS_STORE` 中，**账户自动备份不包含主题**。主题可以从社区目录或 ZIP 重新安装，主题设置需要重新调整。

## 制作主题

- 新增模板仓库 [wuzf/2fa-theme-template](https://github.com/wuzf/2fa-theme-template)：在 GitHub 点 **Use this template** 创建自己的仓库。模板本身就是一个可以安装的完整主题，带开发预览、测试、打包和用 2FA 源码校验主题包的脚本，README 从创建仓库一步步讲到导入和发布。
- **外观与主题** 的「主题」标题旁新增 **制作主题** 链接，打开主题指南。
- [自定义主题](https://github.com/wuzf/2fa/blob/v2.0.0/docs/THEMES.md) 介绍主题的使用、主题目录、自动更新、安全模式和 v1 格式；[完整前端主题与 SDK API 1](https://github.com/wuzf/2fa/blob/v2.0.0/docs/THEME_APP_SDK.md) 说明 v2 的接口、包格式和上架前的检查清单。
- 做好的主题可以只导入自己的实例，也可以放进自己的主题目录，或向官方目录提交 PR，经审核合并后出现在所有实例的社区主题中。

## 自定义代码

- **设置 → 自定义代码** 可以添加多条 HTML、style 和 script 代码，每条有名称和开关，最多 50 条、合计 10 万字符。
- 修改自动保存，停止输入后自动刷新页面生效。
- 自定义代码同样与 2FA 页面同源运行，可以读取账户数据，只添加自己理解和信任的代码。
- 代码导致页面无法使用时，用这一页的 **临时禁用自定义代码** 链接，或访问 `/?safeMode=1` 打开页面后修改。

## 其他改进

- 设置新增 **关于** 页，显示当前版本、新版本提示，以及文档、浏览器扩展、问题反馈和 GitHub 链接。使用主题时页脚由主题提供，这些信息都可以在这里找到；有新版本时，2FA 会显示一条可以关闭的提示。
- 重新打开主页时先显示上次保存的页面，同时在后台核对版本和外观，有变化时自动刷新一次，打开更快；刷新页面时仍先请求服务器。
- 浏览器顶栏和安装为应用（PWA）后的导航栏颜色与主题背景一致。
- 官方界面的搜索框和显示方式、排序按钮在滚动时固定在顶部。
- 提示消息按文字长短显示，并居中。
- 公开验证码页面 `/otp/` 也使用已应用的外观。
- 第一次打开（或强制刷新）的页面在下次加载前还不能离线保存修改，断网时如实提示，不再显示「操作将在网络恢复后自动同步」；联网后刷新一次即可。

## 升级与回滚

1. 升级前导出并保存当前账户数据，保留原 `ENCRYPTION_KEY`、Worker 名称和 KV 绑定。
2. 一键部署用户在 **Actions → Sync Upstream → Run workflow** 选择 `v2.0.0`，等待源码同步及 Cloudflare 构建完成；还没有入口时，按[升级指南](https://github.com/wuzf/2fa/blob/v2.0.0/docs/DEPLOYMENT.md#升级指南)添加。
3. 命令行部署用户同步代码、执行 `npm install`，检查 `wrangler.toml` 后运行 `npm run deploy`。在 Cloudflare Dashboard 中手动配置 Git 构建命令的，部署命令也要用 `npm run deploy`，不要直接写 `npx wrangler deploy`：项目构建会为页面、主题离线快照和功能模块生成一致的构建身份。
4. 刷新网页，确认版本为 `2.0.0`：官方界面看页脚，使用主题时看 **设置 → 关于**。

从 `1.13.1` 或更早的版本升级后，浏览器里仍是旧版 Service Worker，它不能运行完整（v2）主题。只开着一个 2FA 页面时，应用或打开 v2 主题会先下载主题，再换成新版 Service Worker 并自动刷新一次，几秒后主题即可运行；同时开着其他 2FA 页面（包括安装到桌面或手机的应用）时，页面会提示先关闭它们，关闭后点 **重试** 即可，在此之前继续显示官方界面。官方界面、v1 主题和自定义代码不受影响。

安装和应用主题需要 Durable Object 绑定 `SECRETS_STORE`，1.11.0 起的默认配置已包含。没有这个绑定时账户功能照常可用，但只能预览内置主题，不能安装或应用主题。本次没有新增 Durable Object 类或迁移，也不需要 R2 或其他绑定。

> ⚠️ 已使用主题时，迁移到新的 Worker、删除 Durable Object 类，或回滚到 1.11.0 之前的版本（需要删除这个类）都会清空主题库和主题设置，之后需要重新安装主题；保留 KV 也无法恢复它们。

由于没有新的迁移，可以在 Dashboard 的 **Deployments** 页面直接回滚到 `1.13.1`。旧版本没有主题和自定义代码功能，回滚后显示官方界面；已安装的主题、外观设置和自定义代码仍保存在原处，旧版本不会删除它们，再次升级后继续使用。从 `1.11.0` 之前升级，或回滚到 `1.11.0` 之前，仍需遵循[部署与回滚指南](https://github.com/wuzf/2fa/blob/v2.0.0/docs/DEPLOYMENT.md)中的迁移和暂停写入要求。
